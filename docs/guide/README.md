# The bstack guide

bstack connects engineering playbooks, specialist skills and reusable principles through the host's available tools. Start with a goal and a finish condition the agent can check. The runtime resolves roles, access, delegation limits and publication authority.

| Chapter | What it helps you do |
| --- | --- |
| [1. Setup](01-setup.md) | Install skills, inspect effective settings and choose reasoning and agent limits. |
| [2. Start a task](02-poteto-mode.md) | Give a goal, done condition, proof, context and constraints. |
| [3. Understand](03-understand.md) | Investigate behavior, rationale and recent context before editing. |
| [4. Design](04-design.md) | Explore alternatives, prototype and select boundaries before planning. |
| [5. Build and clean](05-build-and-clean.md) | Fix, implement, refactor and measure with concrete evidence. |
| [6. Verify and ship](06-verify-and-ship.md) | Build real-flow proof and carry authorized work through publication. |
| [7. Autonomous runs](07-overnight.md) | Set a trusted finish condition, authority and recovery boundaries. |
| [8. Principles](08-principles.md) | Apply reusable rules at the decision they protect. |
| [9. Make it yours](09-make-it-yours.md) | Capture workflows and lessons with explicit scope. |
| [10. Recipes and pitfalls](10-recipes-and-pitfalls.md) | Pick a starter prompt and avoid common gaps. |

Invoke [poteto-help](../../skills/poteto-help/SKILL.md) for guidance, or [ketchup](../../skills/ketchup/SKILL.md) for a verified catch-up in the current chat. These two skills run only when explicitly invoked. [Poteto Mode](../../skills/poteto-mode/SKILL.md) routes engineering work.

Examples use `/skill-name`; use `$skill-name` or your host's supported invocation syntax where needed. A playbook title is selected by Poteto Mode and is not a separate slash command. Capability-specific instructions remain conditional on the current host.
